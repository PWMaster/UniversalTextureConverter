# Universal Texture Converter

Программа для Windows, которая пакетно конвертирует текстуры между форматами: DDS, TGA, PSD, BMP, PNG, TIFF, WEBP, JPG и GIF. Она обходит папку со всеми подпапками и сохраняет результат с той же структурой каталогов. Сделана для работы с игровыми ресурсами, где тысячи текстур разложены по вложенным папкам.

Автор: [@PW_Master_1](https://github.com/PWMaster)

## Возможности

- **Пакетная конвертация** папок любой вложенности с сохранением структуры каталогов и имён файлов.
- **Многопоточность**: файлы обрабатываются параллельно, число потоков настраивается.
- **Дубликаты**: если рядом лежат одноимённые файлы разных форматов (например, `hair.dds` и `hair.tga`), берётся лучший источник в порядке DDS → TGA → PSD → BMP → PNG → TIFF → WEBP → JPG → GIF.
- **Только изменённые**: пересобираются только новые файлы и те, у которых исходник новее результата.
- **Изменение размера**:
  - увеличение мелких DDS в целое число раз до 64–1024 px;
  - ограничение максимального размера: уменьшение в 2, 4, 8… раз, поэтому размеры-степени двойки остаются степенями двойки.
- **DDS любого типа**: DXT1/3/5 читаются через FreeImage, а BC7, BC6H и прочие через DdsFileTypePlus.
- **Надёжная запись**: файл сначала пишется во временный и только потом переименовывается, поэтому при отмене или сбое недописанных файлов не остаётся.
- **Перетаскивание**: папки можно перетащить в поля путей, а файлы и папки — на окно программы или прямо на `exe`.
- **Отмена** в любой момент, время работы и оценка до конца, прогресс на значке в панели задач, звуковой сигнал по окончании.
- **Лог** каждого запуска в `log.txt`, кнопка «Повторить ошибки», меню по правому клику в списке ошибок.

## Форматы

| Формат | Чтение | Запись | Примечание |
|---|:---:|:---:|---|
| DDS | ✔ | ✔ | запись: DXT1, DXT5, BC7, BC7 sRGB, BGRA без сжатия; мипмапы по желанию |
| TGA | ✔ | ✔ | |
| PSD | ✔ | ✔ | |
| BMP | ✔ | ✔ | |
| PNG | ✔ | ✔ | |
| TIFF | ✔ | ✔ | сжатие LZW |
| WEBP | ✔ | ✔ | качество 1–99 — сжатие с потерями, 100 — без потерь |
| JPG | ✔ | ✔ | качество 1–100, прозрачность отбрасывается |
| GIF | ✔ | — | |

> BC7 и sRGB-варианты поддерживаются только движками на DirectX 11 и новее. Для старых игр используйте DXT1 (без прозрачности) или DXT5 (с прозрачностью).

## Требования

- Windows 10/11 x64
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)

## Использование

1. Укажите **папку импорта** и **папку экспорта**: кнопкой `...`, вводом пути или перетаскиванием папки в поле.
2. Выберите **формат** результата и нужные параметры.
3. Нажмите **«Конвертировать»**.

Можно и без выбора папок: перетащите файлы или папки на окно или на `MyTextureConverter.exe`. Результат сохранится в папку экспорта, а если она не задана — рядом с исходниками.

### Параметры

| Параметр | Описание |
|---|---|
| Перезаписать | конвертировать заново, даже если результат уже есть |
| Только изменённые | конвертировать только новые файлы и те, у которых исходник новее результата |
| Входные | какие форматы брать из папки импорта |
| Увеличивать мелкие DDS до | увеличение DDS, у которых большая сторона меньше выбранного размера |
| Уменьшать больше чем | уменьшение текстур, у которых большая сторона больше выбранного размера |
| Качество | качество JPG и WEBP |
| Потоки | сколько файлов конвертировать одновременно; меньше потоков — меньше расход памяти на больших текстурах |
| Мипмапы (DDS) | создавать мипмапы при сохранении в DDS |

### Файлы рядом с программой

| Файл | Назначение |
|---|---|
| `settings.ini` | пути и все параметры; сохраняется при закрытии программы |
| `log.txt` | подробный лог последнего запуска: успешные файлы, пропуски, дубликаты, ошибки |

## Сборка

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (или Visual Studio 2026).

Сборка для разработки (результат в `bin\Debug\`):

```bash
dotnet build
```

Один исполняемый файл для распространения (результат в `bin\Release\publish\`):

```bash
dotnet publish -c Release
```

## Используемые библиотеки

- [FreeImage](https://freeimage.sourceforge.io/) через [FreeImage.Standard](https://www.nuget.org/packages/FreeImage.Standard): чтение и запись большинства форматов.
- [DdsFileTypePlus](https://github.com/0xC0000054/pdn-ddsfiletype-plus) через пакет [DdsFileTypePlusHack](https://www.nuget.org/packages/DdsFileTypePlusHack): чтение DDS любого типа и сохранение DDS с BC-сжатием.

Условия использования библиотек определяются их собственными лицензиями.
